# Bugfix Log (История исправлений)

Здесь собраны проблемы, с которыми я столкнулся в процессе разработки, и способы их решения.

## v0.0.9

### 1. Некорректная работа `check_confirm` (функция подтверждения)
**Проблема:** Функция `check_confirm` работала неправильно. Она реагировала только на строгое слово "Да" (или "Y"), игнорируя "да", "Yes", "y" и другие варианты. Из-за этого при отказе от действия (ввод "N") приложение могло вести себя непредсказуемо или подтверждать действие.
**Решение:** 
Переписана логика проверки. Теперь функция приводит ввод к нижнему регистру и проверяет вхождение в список разрешенных ответов (`y`, `yes`, `да`, `д`).

### 2. Ошибка в `get_base_dir` (utils.py)
**Проблема:** В функции `get_base_dir` отсутствовал оператор `return`. Из-за этого функция возвращала `None`. В дальнейшем `os.path.join(None, "saves.txt")` вызывал ошибку `TypeError`.
**Решение:** 
Добавлен `return` в обе ветки условия (для `sys.frozen` и для обычного запуска).

### 3. Инверсия логики в `deleated_task` (core.py)
**Проблема:** В функции удаления задачи стояло условие `if not check_confirm(...)`. Это означало, что если пользователь подтверждал удаление, то удаление не происходило.
**Решение:** 
Условие изменено на `if check_confirm(...):` — теперь удаление происходит только при подтверждении.

### 4. Ошибка в `viev.py` (модуль отображения)
**Проблема:** В функции `show_collection` была ошибка с переменной `full_task_list`. При переборе задач она перезаписывалась, и в итоге выводился только последний элемент списка, либо возникал `IndexError` при попытке вывести описание.
**Решение:** 
Исправлена логика работы со списком. Теперь список отображается корректно.

### 5. Отсутствие обработки исключений при вводе чисел
**Проблема:** Если пользователь вводил текст вместо номера задачи при редактировании или удалении, приложение падало с ошибкой `ValueError`.
**Решение:** 
Добавлены блоки `try-except` вокруг `int(input(...))`.

## v0.1.0

### 6. Проблемы с путями при сборке в EXE
**Проблема:** При сборке через PyInstaller путь к файлу `saves.txt` мог определяться неверно.
**Решение:** 
Использована проверка `sys.frozen` для корректного определения директории исполняемого файла (реализовано в `get_base_dir`).

### 7. Ошибка кодировки при чтении файла
**Проблема:** При открытии файла без указания кодировки в Windows могла возникнуть ошибка `UnicodeDecodeError`.
**Решение:** 
Во всех операциях `open()` явно указана кодировка `encoding="utf-8"`.
